# MatchCV

AI-powered resume analyzer that evaluates resumes using Google Gemini AI, generates ATS scores, compares resumes with job descriptions, and provides actionable suggestions to improve interview chances.

> 🚧 Currently under active development.

## Features

- AI-powered ATS Resume Analysis
- Resume vs Job Description Matching
- PDF Resume Upload
- Keyword Analysis
- ATS Score
- AI Suggestions
- Modern Responsive UI
- Built with Next.js 15 + TypeScript + Tailwind CSS + Gemini AI

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Google Gemini AI
- Framer Motion

## Getting Started

```bash
npm install
npm run dev
```
